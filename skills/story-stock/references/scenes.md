# 장면 레시피 — 주장 하나를 그림 하나로

코드 전체는 [scene-library.js](scene-library.js)(17개). 출발점 [starter/src/scenes.js](../assets/starter/src/scenes.js)에는 그중 6개(★)가 들어 있다.
장면은 `scene({ id, len, name, beats, draw(g, p) })`로 정의한다.

- `len`: 스크롤 길이(vh). 박자 2개면 240~300, 3개면 300~360.
- `beats`: `[{ at, tag, plain, q }]`.
  - `at`: 그 박자가 시작하는 진행률.
  - `tag`: "Claude · 시장 분석가"처럼 누가 한 말인지.
  - `plain`: 쉬운 말 한두 문장.
  - `q`: `Q(run, agent, "원문 앞부분")` 또는 `{ text }`.
- `draw(g, p)`:
  - `g.G`: 그래픽 영역(HUD 아래, 캡션 위).
  - `g.m`: 모바일 여부. `g.t`: 시간.
  - 그림 전체가 `p`의 함수여야 한다.

| 장면 | 보여 주는 것 | 필요한 숫자(data.js) | 박자 |
| --- | --- | --- | --- |
| ★ **두 갈래** `s-open` | 같은 점에서 나온 두 실행의 궤적이 에이전트 관문 11개를 지나며 벌어지고, 관문마다 그 에이전트의 등급이 켜진다. 끝에 두 최종 등급이 떠오른다. 모바일은 위→아래 | 관문 이름 · 실행별 등급 문자열 · 벌어짐 정도(SPREAD) | 질문 → 결론 |
| **같은 가격표** `s-same` | 두 실행이 받은 스냅샷 숫자가 두 줄로 떨어져 `=`로 이어진다. 표기만 다르면 `≈`와 테두리 | 종가 · 평균선 · RSI · MACD · ATR | 같다 → 표기 차이 |
| ★ **천장 아래로** `s-slide` | 가격선이 화면을 가로질러 스스로 그려지고, 10일 · 50일 평균선이 천장처럼 내려와 머리 위에 걸린다 | 날짜 붙은 종가 몇 개 · 평균선 값 | 미끄러짐 → 천장 |
| ★ **RSI 바늘** `s-rsi` | 반원 계기판에서 바늘이 과거 구간에서 과매도(30) 문턱까지 가라앉는다. 큰 숫자는 보고서의 현재 값으로 고정 | 과거 RSI 구간 · 날짜별 RSI · 현재 RSI | 바늘 하강 → 바닥 아님 |
| **MACD 낙하** `s-macd` | 막대가 0선 아래로 내리꽂히고(충격 링), 시그널 점선이 깔린다. 이어서 히스토그램이 짧아진다 | 날짜별 MACD · 시그널 · 히스토그램 두 시점 | 낙하 → 둔화 |
| ★ **하루 흔들림** `s-shake` | 종가를 감싼 ±ATR 띠가 떨고, 예시 흔들림 선이 지나가며 손절선 아래로 갈 때마다 "손절"이 터진다 | 종가 · ATR · 손절가 · 볼린저 하단 | 흔들림 → 손절이 묻힘 |
| **200일선 바닥** `s-floor` | 한쪽만 그은 장기 평균선이 빛나는 바닥으로 올라오고, 가격이 그 바로 위에 선다. 장중 저가로 빠졌다 돌아온다 | 장기 평균 시점별 값 · 종가 · 장중 저가 | 바닥 → 장중 이탈 |
| **다른 선 하나** `s-split` | 화면이 둘로 갈려 같은 가격을 한쪽은 바닥 위, 한쪽은 천장 셋 아래로 본다. 판정 도장이 찍힌다 | 공통 평균선 · 실행별로 더 본 선 | 다른 선 → 다른 등급 |
| **실적 폭발** `s-boom` | 분기 매출 기둥이 솟고 불꽃이 튄다. 이익률 고리가 채워진다 | 분기 매출 · 이익률 | 매출 → 이익률 |
| **꼭대기 경고** `s-cycle` | 분기 이익률이 산맥이 되고 꼭대기가 경고등처럼 깜박인다. 아래로 과거 손실 분화구가 패인다 | 분기별 이익률 · 영업이익 | 산 → 분화구 |
| **두 배가 된 빚** `s-debt` | 부채 기둥은 두 배로, 현금 기둥은 조금만 자라고 "+차이"와 "왜?"가 뜬다. 자라는 중에는 시작 값을 흐리게 보여 준다(중간값 금지) | 부채 · 현금 전후 값 · 증가분 | 증가 → 차이 |
| **강세 대 약세** `s-forces` | 가격 판을 강세 화살표가 밀어 올리고 약세 화살표가 눌러 내린다. 마지막에 위아래 목표가 같은 길이로 맞선다 | 현재가 · 상방 · 하방 목표 | 강세 → 약세 → 대칭 |
| **두 매니저** `s-scales` | 저울 두 개가 같은 쪽으로 기울고, 한쪽은 잠기고("멈춤") 다른 쪽은 더 기운다("지금 줄인다") | (문장만) | 기울기 → 잠김 → 더 기욺 |
| ★ **인계철선** `s-wire` | 보유 비중 막대 두 개. 한쪽은 지금 절반으로 줄고, 다른 쪽은 붉은 줄을 쳐 두었다가 "만약" 공이 줄을 넘는 순간 줄어든다 | 현재가 · 기준선 · 줄일 비중 | 지금 → 줄 → 만약 |
| **갭과 리스크 셋** `s-gap` | 실적 다음 날 가격이 기준선을 건너뛰어 아래에서 시작하는 갭, 그리고 리스크 분석가 셋의 비중 막대 | 현재가 · 기준선 · 갭 시작가 · 분석가별 비중 | 갭 → 한쪽 셋 → 다른 쪽 셋 |
| ★ **한 칸 차이** `s-land` | 두 혜성이 등급 다섯 칸(매수 · 비중 확대 · 보유 유지 · 비중 축소 · 매도) 위로 날아와 각자의 칸에 내려앉는다 | 최종 등급 | 착지 → 행동 |
| **다음에 볼 줄** `s-next` | 지금 가격 위아래로 각 실행이 걸어 둔 조건선이 맥박친다. 누구의 조건인지 색과 이름으로 표시 | 조건 가격들 | 한 박자 |

## 만들 때 지킬 것

- **숫자 라벨은 보고서 값만 쓴다.**
  - 자라는 막대, 움직이는 바늘, 줄어드는 비중에 중간값을 찍지 않는다.
  - 끝값을 서서히 나타내거나, 시작값 → 끝값으로 바꾼다.
- **예시 곡선은 「예시」라고 화면에 적는다.** 흔들림처럼 데이터가 아닌 선이 그렇다.
- **색만으로 구분하지 않는다.** 실행 색 옆에 `Claude` · `GPT` 같은 이름, 선 옆에 이름과 값을 붙인다.
- **모바일(`g.m`)은 다시 배치한다.**
  - 가로 축은 세로로 돌린다. 반으로 나누는 장면은 위/아래로 나눈다.
  - 라벨은 화면 안쪽으로 정렬한다.
- **계기판 · 큰 숫자는 바깥 라벨까지 `g.G` 안에 넣는다.**
  - 반지름 = `min(가로 비율, 중심 y - G.y - 라벨 여백)`.
  - 1440×900 · 1280×720 · 390×844에서 확인한다.
- **동작 줄이기:**
  - `Engine.reduce`면 시간 떨림은 0으로 둔다.
  - 진행률은 boot.js가 박자 끝으로 맞춰 주므로, 그 박자의 완성 상태만 그리면 된다.
- **장면 사이 전환**은 boot.js가 처리한다. 장면은 신경 쓰지 않아도 된다.
  - 나가는 그림은 무대가 밀려나기 시작하면 사라진다.
  - 들어오는 그림은 절반 넘게 들어온 뒤 켜진다.
